### [`ghoul`](https://github.com/rephuren/ghoul): SSH-ловушка с живым дашбордом

Притворяется взломанным сервером. Боты со всего интернета заходят внутрь, а `ghoul` записывает пароли, которые они перебирают, команды, которые запускают, и адреса, откуда скачивают вредоносы. Ничего из этого не исполняется, оболочка поддельная.

Python · asyncssh · SQLite · свой веб-дашборд
